# DO_NOT

A tiny webpage built around one simple rule:

**don't press the button.**

Of course, you probably will.

## What happens?

Every click changes the page a little bit.

- The messages get increasingly annoyed
- The page eventually switches to dark mode
- The button starts moving around
- The ending gives you an `again` button so you can start over

There isn't really a useful reason for any of this. I just thought it would be fun.

It is packed into a single Data URI and kept under the SHRINK 3 KB limit.
